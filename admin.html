🔧 Suporte técnico
"Ação desconhecida" ao gravar ▼
O Apps Script precisa ser republicado: Implantar → Gerenciar implantações → ✏️ → Nova versão → Implantar. A URL não muda.
Dados não carregam ao abrir ▼
Verifique: (1) Web App publicado como "Qualquer pessoa"? (2) Abas existem na planilha? (3) Abra a URL do script direto no navegador — deve aparecer ok:true.
Como adicionar novo admin ▼
Na planilha: menu 🏛️ Terreiro → Gerenciar admins → OK. Preencha usuário, nome, senha provisória, nível e permissões. O admin troca a senha no primeiro acesso por este painel.

configuracoes — gerenciar admins
Critério de qualidade para busca no ML ▼
A busca retorna os primeiros resultados do Mercado Livre. Defina internamente o padrão de cada item (ex: marca preferida para velas) e use o campo "Fornecedor" para registrar. O link é referência de preço — a decisão final é sempre de quem compra.
Como atualizar o app (nova versão) ▼
Substitua o(s) arquivo(s) HTML no GitHub. O Pages atualiza em minutos. No celular, force limpando cache: Chrome → 3 pontos → Atualizar.
