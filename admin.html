🔧 Problemas comuns
Aparece "Ação desconhecida" ao gravar ▼
O código do Apps Script precisa ser republicado. No editor: Implantar → Gerenciar implantações → lápis ✏️ → Nova versão → Implantar. A URL permanece a mesma.
Os dados não carregam ao abrir o app ▼
Verifique: (1) o Web App está publicado com acesso "Qualquer pessoa"? (2) o setup() foi executado e as abas existem na planilha? (3) Abra a URL do Apps Script diretamente no navegador — deve aparecer {"ok":true,"msg":"Web App ativo."}
Como atualizar o app quando houver versão nova ▼
Substitua o arquivo index.html e/ou mobile.html no repositório do GitHub. O GitHub Pages atualiza em alguns minutos. No celular pode levar até 24h — force limpando o cache: no Chrome, 3 pontos → "Atualizar".
Como trocar a senha de acesso a esta página ▼
Edite o arquivo admin.html e localize a linha: const SENHA = '...'. Troque pelo valor desejado e suba o arquivo atualizado no GitHub.
Como adicionar um item de consumível que não está na lista ▼
Na aba Consumíveis do app (desktop ou celular), role até o final — há um formulário "Cadastrar novo item". Preencha nome, categoria, unidade, quantidade atual e mínima.
Critério de qualidade para busca de preços no Mercado Livre ▼
A busca retorna os primeiros resultados do ML — nem sempre são os de melhor qualidade. Recomendamos definir internamente o padrão de cada item (ex: "vela 7 dias — preferência por marcas X ou Y") e usar o link apenas como referência de preço. O fornecedor preferido pode ser cadastrado manualmente no campo "Fornecedor" de cada item.
