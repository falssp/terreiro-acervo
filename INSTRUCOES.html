Parte 1 — Configurar o Google Sheets
1

Abrir a planilha

A planilha já foi criada na sua conta. Acesse:
→ Abrir planilha no Google Sheets

2

Abrir o Apps Script

No menu da planilha: Extensões → Apps Script
Uma nova aba vai abrir com o editor de código.

3

Colar o código

Selecione todo o código que estiver no editor (Ctrl+A) e apague. Cole o conteúdo do arquivo Terreiro_AppsScript.gs. Salve com Ctrl+S.

4

Executar o setup

No dropdown de funções (onde aparece o nome da função), selecione setup. Clique em ▶ Executar. Autorize quando o Google pedir. Uma caixa vai confirmar: "✅ Acervo do Terreiro configurado!"

⚠️ O setup cria as abas Acervo e Estoque já formatadas, com validações e sem linhas/colunas vazias.
5

Publicar como Web App

1. Clique em Implantar → Nova implantação
2. No ícone de engrenagem ⚙️, escolha App da Web
3. Configure:
  • Executar como: Eu mesmo
  • Quem tem acesso: Qualquer pessoa
4. Clique em Implantar
5. Autorize novamente se pedido
6. Copie a URL que aparece (termina em /exec)

✅ URL copiada? Guarde-a — você vai colar no campo do app na Parte 3.
6

Se precisar atualizar o script no futuro

1. Altere o código no editor
2. Implantar → Gerenciar implantações
3. Clique no lápis ✏️ da implantação existente
4. Em "Versão", escolha Nova versão
5. Clique em Implantar — a URL permanece a mesma

Parte 2 — Publicar no GitHub Pages
1

Criar conta no GitHub

Acesse github.com e crie uma conta gratuita (se ainda não tiver).

2

Criar repositório

Clique em New repository (botão verde). Nome: terreiro-acervo. Marque Public. Clique em Create repository.

3

Upload dos arquivos

Na página do repositório, clique em "uploading an existing file". Arraste os 6 arquivos da pasta do projeto:
index.html · manifest.json · sw.js · icon-192.png · icon-512.png · Terreiro_AppsScript.gs
Clique em Commit changes.

4

Ativar o GitHub Pages

1. Clique em Settings (no repositório)
2. Menu lateral: Pages
3. Source: Deploy from a branch
4. Branch: main · Pasta: / (root)
5. Clique em Save
6. Aguarde ~2 minutos
7. Sua URL vai aparecer: https://seu-usuario.github.io/terreiro-acervo

Parte 3 — Configurar e usar o app
1

Colar a URL do Apps Script

Abra o app no navegador. No campo "URL do Apps Script" no topo, cole a URL copiada na Parte 1 (passo 5). Ela é salva automaticamente.

2

Instalar no celular — Android (Chrome)

Abra a URL no Chrome. Um banner vai aparecer: "📲 Instalar na tela inicial?" Toque em Instalar. Se não aparecer: 3 pontos → Adicionar à tela inicial.

3

Instalar no celular — iPhone (Safari)

Abra a URL no Safari (não funciona no Chrome do iOS). Toque no botão de compartilhar 📤 → Adicionar à Tela de Início → Adicionar.

Parte 4 — Usar o app
1

Aba Cadastrar

Preencha Nome e Categoria (obrigatórios) + os demais campos. Toque em Gravar na planilha. O item aparece instantaneamente na aba Acervo da planilha.

2

Aba Acervo

Toque em ⟳ Atualizar para carregar os itens. Use os filtros de categoria, orixá e status para buscar.

3

Aba Estoque

Toque em ⟳ Atualizar para ver o painel. Role até o formulário para cadastrar um item. Informe nome, quantidade atual e mínima. Se o item já existir pelo nome, ele é atualizado (não duplicado).

✅ Em dia — quantidade atual ≥ mínima
⚠️ Repor — entre 50% e 99% do mínimo
🔴 Crítico — menos de 50% do mínimo

💡 Em caso de dúvida, verifique: (1) a URL termina em /exec, (2) o Web App tem acesso "Qualquer pessoa", (3) o setup() foi executado e as abas Acervo e Estoque existem.
